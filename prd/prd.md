# PRD — Modern High-Tech Portfolio & Digital Agency Website

เวอร์ชัน: 1.0
ผู้จัดทำ: PM AI Assistant
ประเภทโครงการ: Portfolio + Digital Agency + Lead Generation Platform
เป้าหมาย: สร้างเว็บไซต์ Portfolio ระดับมืออาชีพสำหรับนำเสนอผลงาน รับลูกค้าใหม่ และบริหารบริการ/ราคา/คอนเทนต์ได้ด้วยตนเอง

## Tech Stack
- Next.js
- shadcn-ui

# 1. Product Overview

## 1.1 Vision

สร้างเว็บไซต์ Portfolio และ Digital Agency Platform ที่มีภาพลักษณ์ “Modern / Futuristic / High-Tech” 
with cyberpunk aesthetics, use neon on dark,use professional colors on light. 
เพื่อใช้เป็นศูนย์กลางในการ:

* แสดงผลงาน
* สร้างความน่าเชื่อถือ
* รับลูกค้าใหม่
* นำเสนอราคาและบริการ
* ปิดการขายผ่านเว็บไซต์
* จัดการคอนเทนต์และข้อมูลได้จาก Admin Dashboard

---

# 2. Business Goal

## Primary Goals

* เพิ่มจำนวนลูกค้าใหม่ (Lead Generation)
* เพิ่ม Conversion จากผู้เข้าชม → ผู้ติดต่อ
* เพิ่มความน่าเชื่อถือของแบรนด์
* สร้างภาพลักษณ์ Tech Company ระดับ Professional
* ลดเวลาการตอบคำถามซ้ำ ๆ ด้วยระบบราคา/FAQ/บริการ
